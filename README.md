# zugliandroid (Golden Gate Bridge Android)


This is a port of the [Golden Gate](https://github.com/TheEnbyperor/golden-gate) iOS application
which allows users of [Zügli](https://github.com/TheEnbyperor/zuegli) to read NFC smart cards
containing train tickets

# Installation

The app can be installed through [F-Droid](https://drschlaubi.github.io/zuegliandroid/repo)
or [GitHub releases](https://github.com/DRSchlaubi/zuegliandroid/releases/latest)

after installing the app you have to [grant it access to open its requested urls](#grant-url-access)

# Usage

You can start the scanning process through any Zügli instance, the official one can be found
here: [zuegli.app](https://zuegli.app/vdv_smartcard)

#### Grant URL access

1. Open App Info page
2. Open the "open by default" section
3. click on add link
4. check both boxes
5. finish
